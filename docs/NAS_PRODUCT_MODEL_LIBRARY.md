# 商品 3D 建模庫操作說明

入口：http://127.0.0.1:8790/admin/recipes/models

目前預設開啟「產品模板」，將已生成模型與待完成草稿分列。NAS 歷史檔案放在「素材資料庫」，不會自動成為模板。完整新版流程與用途分類請見 [模板與素材操作說明](ASSET_USAGE_TEMPLATE_LIBRARY.md)。

1. 從「產品模板」選草稿，補齊外形尺寸（mm）、板厚及結構依據；未知欄位保持空白。
2. 找來源時切換「素材資料庫」，搜尋 NAS 資料夾，按「預覽並分類素材」。查看檔案不會改動模型。
3. 要建立新模型，按「從此資料夾建立模型草稿」，再填寫並儲存。
4. 素材必須逐頁核對用途；只有明確分類為印刷圖稿的素材可關聯至 SKU 或印刷工單。
5. 支援配方的尺寸與結構資料補齊後，確認簡化說明並生成 3D 預覽。完成可旋轉查看、下載，並自動移入已生成模型列表。
6. 相同尺寸與結構才共用模型。圖稿欄目前只保存關聯，不會自動貼到新模型；印刷面紀錄尚未校準。

## 首批資料的邊界

已盤點的檔案數與資料夾群組數不是已建模商品數。七類各建立一筆人工整理的 NAS 參考資料；目前這七筆皆有未確認結構，未生成商品精準模型。外形參考尺寸不是印刷面尺寸。

| 類別 | 已讀到的資料 | 還需要 |
|---|---|---|
| 杯墊 | 總覽10×10 cm，混合硬式／軟式與其他SKU背標範例 | 正確SKU對應、厚度、圓角或刀模 |
| 地墊 | 60×39×0.9 cm商品尺寸圖 | 圓角半徑、正式刀模、印刷面原點 |
| 木櫃 | 42×30×90 cm三層空櫃尺寸圖 | 板厚、背板厚、板件接合與印刷面尺寸 |
| 門簾 | 雙片中央開縫商品照片 | 展平尺寸、開縫、布厚、縫份 |
| 口罩收納盒 | 18.4×10.4×1.5 cm商品說明 | 上蓋、圓角、鉸接、印刷刀模 |
| 50入收納盒 | 20.5×10.5×13 cm尺寸圖 | 盒體曲面、上蓋、扣件與印刷刀模 |
| 噴瓶 | 直徑3.3 cm、高14.3 cm、50 ml商品圖 | 各段直徑、蓋與泵頭、可印高度、曲面展開 |

65×45 是貼紙尺寸，不用於商品建模。照片、吊卡或文件頁面大小不會自動成為商品尺寸。來源圖上的規格是參考，仍需要實物核對。

既有圖稿與UV印刷工作台可繼續使用；本輪不觸發AI供應商、RIP或實體機台，也不自動合併PR。

## 管理員設定與資料保存

本機來源已設定。其他安裝環境可執行 `scripts/configure_nas_product_catalog.py --data-root <local-data> --product-root <selected-product-root> --wood-root <optional-wood-root>`。瀏覽器不接收任意檔案路徑；設定檔與 NAS 索引都留在本機資料目錄，不上傳 GitHub。重新掃描不完整時保留上一份完整索引。

模型資料保存於工作區下的 `product-masters`，包含不可覆蓋的歷史版本；圖稿以原始位元組 SHA-256 保存。兩個相同尺寸的資料夾不會自動合併為同一商品。

模型預覽使用獨立 `nas-models/recipe-previews` 目錄，沿用既有序列生成、取消、真實 Blender 匯出及校驗流程。未提供圓角、曲面、開縫、抽屜、鉸接等結構時不建立近似配方；櫃體配方的等高格位與內嵌背板仍屬明示的預覽簡化。後續修改配方需同步更新預覽版本與失效策略。

驗收紀錄見 `NAS_PRODUCT_MODEL_ACCEPTANCE.md` / `.json`。
