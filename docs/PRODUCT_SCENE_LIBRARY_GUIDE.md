# 客廳與廚房情境出圖

1. 在模型工作台選擇已有外形預覽的商品，往下找到「情境場景庫」與「換圖與情境預覽」。
2. 選每片門或平板正面的圖稿，填本次款式名稱。
3. 「展示場景」選客廳或廚房。「擺放位置」通常保留自動：木櫃／地墊在地板，杯墊在客廳茶几或廚房檯面。
4. 選右前方、左前方或正前方，確認用途後生成。
5. 要多款一起做，在下方勾選客廳／廚房，按「將上方款式加入批次」。改圖或角度再加入，核對清單後「生成整批款式」。一批最多 24 款；換不同圖請使用不同款式名稱。
6. 成果庫下載情境圖。正面核對圖維持商品原座標；GLB 只包含商品；Blender 檔同時保留商品核對場景及有家具的情境場景，開啟時顯示後者。

擺放範圍：櫃體寬 1200、深 700、高 2100 mm 以內；地墊寬 1200、長 800、厚 50 mm 以內；杯墊寬／長 450、厚 50 mm 以內。超出範圍會拒絕，不會把商品縮小。茶几高 460 mm、廚房檯面高 900 mm，皆為展示場景設定。

商品尺寸、網格、材質及貼圖沿用母版。平板以整體旋轉平放，貼圖朝上。房間中的家具是程序建立的展示模型，不代表真實住宅或家具工程規格。曲面瓶身、盒子、門簾及其他特殊產品仍需專用擺放配方；不能把未完成母版當作已建模商品。沒有新增 AI 背景生圖、照片透視合成、場景上傳編輯器或印刷機控制。
