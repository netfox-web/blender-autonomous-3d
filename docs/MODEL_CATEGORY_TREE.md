# 商品模型分類操作

入口：http://127.0.0.1:8790/admin/recipes/models

## 找模型

左側選商品分類。木櫃可展開「空櫃／門櫃」，再選 2、3、4、5 層；滑門櫃和書櫃獨立保留。地墊、杯墊、洗漱墊、床邊櫃、旋轉木櫃在上層；原有門簾、收納盒、噴瓶放在「其他商品」。點「查看全部木櫃」可包含所有木櫃子分類。

右側可搜尋模型名稱或 SKU，並選擇「已生成模型／待完成草稿」。左側數字是該分類連同子分類的模型總數，不受右側搜尋影響；全頁上方顯示全部模型狀態。這些數字不包含 NAS 素材檔案。

## 調整分類

選一個模型，到「模型所在分類」選最下層分類，按「儲存分類」。依既有模型欄位推定的初始分類會標示「依模型欄位暫分，可調整」。人工儲存後有自己的分類版本；兩人同時修改時，較舊版本會被阻擋，按「重新載入分類」再核對。

分類獨立保存，不更改母版尺寸、結構、SKU 圖稿或已生成檔案。因此移動分類不需要重新跑 Blender。分類不是實際結構證明，也不會讓模型取得製造／印刷認證。若商品類別與目的分類不合，會要求先核對商品資料。

## 新增草稿

選最下層分類，按「在此分類建立草稿」，填名稱並儲存。可帶入商品類別和使用者指定的層數；尺寸、板厚和結構證據保持空白，外形配方仍為「待建立配方」。需要核對後選擇正確配方，才可生成。分類沒有模型時顯示 0，不會自動建立假模型。

旋轉木櫃、特殊床邊櫃和未驗證的墊類不能只靠分類名稱生成準確結構，仍需實際尺寸或正式圖面。分類中顯示已生成，也只是目前具備有效 3D 預覽，並非實物量測或印刷校準完成。

## 貼皮與圖案

這棵樹只管理商品及櫃型。貼皮圖檔屬於素材；完整貼皮管理應另有材質庫，保存材質編號、實際紋理比例、方向、封邊搭配，再讓商品 SKU 指定母版、材質與印刷圖稿。同結構、同尺寸換貼皮可共用母版；板厚或結構改變則需另一個模型版本。

本輪尚未新增材質庫、貼皮選擇或板件材質套用功能，也不會把貼皮素材自動確認為可印刷 ARTWORK。
