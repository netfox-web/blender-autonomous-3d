# 模板庫與素材資料庫

入口：http://127.0.0.1:8790/admin/recipes/models

## 模板與素材分開使用

預設「產品模板」頁只列出已儲存的模型資料。已生成模型和待完成草稿分列，NAS 掃描檔案不會自動成為模板。已生成僅表示有符合目前資料的有效 3D 外形預覽，仍須實物尺寸核對；不是精準印刷認證。

1. 在「產品模板」選草稿，補齊外形、結構和尺寸依據。相同結構與尺寸才共用；不同圖案用 SKU／圖稿關聯管理。
2. 要找歷史檔案，切換「素材資料庫」。搜尋 NAS 資料夾並查看檔案，這不會覆蓋正在編輯的模型。
3. 確實需要新模型時，按「從此資料夾建立模型草稿」，填寫後再儲存。按鈕只建立表單草稿，不會把整個資料夾變成模型。
4. 在素材檔案按「預覽並分類素材」，到「素材用途管理」核對圖片或 PDF 各頁，選用途並填判定依據。
5. 只有已確認的「印刷圖稿」可選入模型 SKU 與印刷工作台。確認全部頁面都是產品印刷圖稿後勾選確認並儲存。圖稿關聯目前不會自動貼到新模型上。
6. 從印刷工作台匯入或從 PrintFox 匯入圖片，也需要先到素材用途管理分類，再重新載入印刷工作台選用。

| 素材用途 | 使用方式 |
|---|---|
| 待分類 | 尚未確定用途；不可套圖或輸出印刷包 |
| 商品參考圖／電商圖 | 外觀、樣品、情境照片及混合設計總覽；不當作印刷原稿 |
| 尺寸／結構圖 | 人工讀取尺寸與結構的依據；不自動認證尺寸，也不作套圖原稿 |
| 刀模 | 待核對的外形與定位資料；不直接當作產品圖案 |
| 印刷圖稿 | 人工核對可作產品印刷圖案的完整原稿；仍需尺寸、出血、方向及實機校色 |
| 貼紙／吊卡／包裝 | 包裝用途，不作產品外形尺寸或產品表面圖案 |

`.ai` 或 `.pdf` 不等於印刷原稿：它也可能是混合商品圖、說明、貼紙與圖案的設計總覽。多款合版來源需先拆分並核對單件內容，不能把整張大版面直接套入單件產品。

## 已有資料如何處理

既有未分類素材預設不能選用於模型或印刷；既有模型／工單與原始檔案仍保留。分類為參考用途後，相關套圖、輸出與下載會被擋下，需改選合適圖稿再儲存。若有舊關聯，選單顯示停用原因，不會默默改成另一張圖。

用途變更會保存判定依據、時間及歷史版本；同一素材重複匯入或改檔名不會清除分類。此為本機操作人員用途判定，不是身份驗證、物理尺寸或印刷放行。
