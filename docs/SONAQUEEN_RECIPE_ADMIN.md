# 商品 Recipe 後台操作

後台入口：[商品 Recipe 庫](http://127.0.0.1:8790/admin/recipes)。這是此電腦上的管理工具；尚未部署到 `home.sonaqueen.com.tw` 官網。官網仍是商品參考資料來源。

## 開啟後台

在 `E:\projects\sonaqueen-recipe-library` 執行：

```powershell
python scripts/run_recipe_admin.py
```

預設只監聽 `127.0.0.1:8790`。瀏覽器開啟 `/admin/recipes` 即可操作，也可從同一服務的 `/admin` 右上角「商品 Recipe 庫」進入。原本的 8788 服務須更新程式並重啟才會出現新入口；這次使用獨立 8790 服務。

若另開測試環境，可指定不同連接埠和資料目錄：

```powershell
python scripts/run_recipe_admin.py --port 8791 --data-root .fox3d-work/ui-qa
```

## 日常操作

1. **找商品**：左側搜尋商品名稱或 SKU，也可依結構配方篩選。目前提供十二格書櫃、四門櫃、六格滑門櫃三款。
2. **補規格**：點選商品，在「規格與缺漏」填入尺寸、材質、板厚、五金與機構資料。尺寸單位為毫米，未確認的數值留白。
3. **記錄依據**：展開欄位下方「補充資料依據」或「查看／編輯資料依據」，填寫供應商圖面、規格書或量測說明。若改了數值卻保留原依據，儲存時會清除該依據，避免把新數值誤記為原始來源所證實。
4. **儲存草稿**：點表單下方「儲存草稿」。成功後會顯示草稿版本及時間，重新載入或服務重啟後仍保留。
5. **驗證資料**：儲存後按「驗證資料」，查看缺漏、尚無依據的欄位，以及門片／格位結構問題。
6. **管理圖片**：切換「圖片與來源」，可查看原始商品圖、尺寸圖、官網連結及來源雜湊；按「上傳圖片」新增 PNG／JPEG 參考圖，每張上限 8 MB。
7. **新增商品**：右上角「＋ 新增商品」，填 SKU、名稱和結構配方，尺寸可稍後補齊。SKU 建立後不可更改，重複 SKU 會被拒絕。
8. **匯出／匯入**：可匯出單一商品或全部商品 JSON，再用「匯入草稿」新增到另一份工作資料。每次匯入 1–100 款、檔案上限 8 MB；若任一 SKU 已有草稿，整批拒絕，保護既有資料。供應商初始商品尚未產生草稿時，可匯入其草稿。

未儲存的變更會有提示；切換商品或重新載入時會提醒。多個視窗編輯同一商品時，過期版本會被拒絕，請先另存自己的修改文字，再重新載入最新版本。

## 保存與備份

預設工作資料位於 `.fox3d-data/recipe-workbench/`：

- `drafts.sqlite3`：目前草稿、每次儲存的版本紀錄及圖片關聯。
- `images/`：上傳圖片實際檔案，以工作區與內容雜湊區分。

UI 使用固定工作區 `sonaqueen-home`。API 的工作區欄位用於資料隔離，並非登入／權限系統；目前定位為本機操作工具。

JSON 匯出包含最新草稿、原始來源描述、驗證結果和圖片中繼資料；**不包含圖片位元組或完整歷次版本**，不是完整備份。匯入時須重新上傳圖片；若要完整備份，先停止此服務，再複製整個 `recipe-workbench` 目錄。重新開服務時須使用原本的 `--data-root` 才會讀到原資料。

此後台 JSON 格式為 `fox3d.recipe-workbench.v1`，與舊 `inspect_recipe_library.py` 的 Registry 匯出格式用途不同，不能混用匯入。

## 資料狀態

原始供應商目錄與快照保持不變，使用者修改另存 SQLite 草稿。來源完整性檢查只證明原始快照未被變更；手動輸入、上傳圖片及文字依據仍是待確認的參考資料。

即使欄位填齊，商品仍不會自動升級為工程核定、可渲染或可生產。三種結構仍需各自完成幾何、機構與 REAL Blender 驗證。新增 UI 不代表完成這三款商品的 3D 模型，也不解除 Phase 961+ HOLD。

## 驗收重跑

先通過 CODE commit 的 Ubuntu／Windows CI，在該 CODE 的 clean working tree 執行：

```powershell
python scripts/run_recipe_admin_e2e.py --expected-commit <CODE_SHA>
```

腳本使用真實本機 HTTP 服務和暫存資料目錄，測試新增／編輯、版本衝突、驗證、圖片上傳／讀取、匯出／匯入、工作區隔離及服務重啟後持久保存。報告寫入 `.fox3d-data/recipe-admin-acceptance/<generation>/report.json`。這是後台 HTTP 驗收，瀏覽器操作另外記錄，不代表 Blender 出圖驗收。
