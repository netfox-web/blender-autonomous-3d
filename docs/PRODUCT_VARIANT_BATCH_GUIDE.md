# 同一母版，批次換圖與背景

1. 開啟 http://127.0.0.1:8790/admin/recipes/models，從左側分類選擇已完成外形預覽的模型。
2. 在「換圖與情境預覽」填一個容易辨認的款式名稱，替每片門、背板或平板正面選圖稿、頁碼與旋轉。圖稿需與該面同一長寬比例，不會自動拉伸。
3. 到「批次款式與成果庫」勾選背景，按「將上方款式加入批次」。換另一款圖時改款式名稱，再加入。送出前可移除清單中的項目。
4. 核對清單，勾選展示預覽確認，再按「生成整批款式」。每批最多 24 款，由同一佇列逐款生成；同一模型不能同時再送單張工作。
5. 每款完成後會出現在成果庫，可下載情境圖、正面核對圖、GLB 或 Blender 母版。換下一張圖不覆蓋前一款。

取消會保留已完成成果。關閉網頁不停止服務中的工作；若關閉服務／電腦，中斷項目不會自動續跑，重新開啟後請核對再加入。

母版修改或圖稿用途撤銷後，既有成果保留紀錄，但停用下載。NAS 原始檔不會被寫入或修改。

## 目前可用的範圍

- 既有規則平板、開放櫃、門櫃及 Recipe 參考模型。
- 白底棚拍、暖色簡易背景、冷色簡易背景；尚非完整房間場景庫。
- 已核對用途的圖片／PDF 相容圖稿。AI 生圖可先匯入圖稿庫並分類；本功能本身不呼叫 AI 生圖 provider。
- 尺寸與材質是展示預覽，不是工廠印刷放行。

## 還需補齊

- 真實櫃型的板厚、背板結構、門縫、門片缺口輪廓；床邊櫃抽屜與腳、旋轉櫃的靜態結構及機構資料。
- 地墊／杯墊／洗漱墊的厚度、圓角、正式刀模。盒子與噴瓶的曲面、印刷區與專用模型配方。
- 可重用的貼皮紋理／材質庫，及客廳／臥室／浴室等完整場景庫。
- UV 生產需要刀模、出血、治具原點、色彩與實機試印，不能直接用情境圖當印刷檔。

PR #13 的開門動畫仍須等待 PR #14 經授權進入 main，本次靜態批次功能未繞過該門檻。

## 批次紀錄核對（Round 2）

批次與每款成果會核對送出時的母版、圖稿選擇、款式順序與已發布檔案。紀錄遺失、損壞或不符時，工作台會顯示錯誤並清除舊的批次進度，請重新核對後建立新批次。圖稿撤銷或母版尺寸改變時，原本完成的款式會顯示核對失敗並停用下載。

重啟後，已完成且仍有效的成果可繼續下載；未完成項目顯示「已中斷」，不會自動重新生成。取消的項目保持取消狀態。舊版未保存完整批次身分的紀錄也需重新核對；獨立成果仍使用原本的成果驗證與下載流程。


## 模型來源與展示用途（Round 3）

新批次會保存每款送出時的來源快照。結果旁會顯示「合成測試模型」、「Recipe 參考，未實測」或「人員填寫，未實測」，以及展示素材是否可下載。「可下載展示素材」只表示圖像與 3D 成果驗證通過；製造與印刷尚未放行。分類樹位置、Blender 成功、AI 推測或填寫尺寸，都不會變成實測／CAD 簽核。

母版另存新版本後，舊批次不能當成目前版本完成的工作。若母版內容相同、原始來源快照與圖稿版本仍有效，舊成果仍可能作為歷史展示素材下載；它保留原本來源，不會改綁最新版。來源撤銷、快照缺失、圖稿版本改變或檔案驗證失敗時，下載會停用。

舊批次若尚無完整來源快照，請核對模型與圖稿後重新送出；系統不會自行替舊成果補上實測資格。成果庫會另外檢查既有歷史成果，仍有效的展示素材可以保留使用。

本輪沒有接入實測／CAD 工程簽核、正式刀模權威或實機試印。取得這些依據以前，請勿把預覽成果當作直接製造或 UV 印刷的放行檔。
